# HELPVET — демонстрация сайта для телефона

Готовый статический сайт для GitHub Pages. Сборка, Node.js и установка библиотек не нужны.

## Опубликовать через сайт GitHub

1. Войдите в GitHub и создайте новый репозиторий, например `helpvet-preview`. Для бесплатной публикации выберите **Public**. При создании можно включить **Add a README file**, чтобы сразу появилась ветка `main`.
2. Распакуйте `helpvet-github-mobile.zip` на компьютере.
3. В репозитории выберите **Add file → Upload files**.
4. Перетащите **содержимое распакованного архива**, включая папку `assets`. Не загружайте сам ZIP и не добавляйте лишнюю внешнюю папку. Файл `index.html` должен лежать в корне репозитория, рядом с `style.css` и `app.js`.
5. Нажмите **Commit changes**. Если GitHub предложит заменить первоначальный README, используйте этот файл.
6. Откройте **Settings → Pages**.
7. В блоке **Build and deployment** выберите **Source → Deploy from a branch**.
8. Выберите **main**, папку **/(root)** и нажмите **Save**.
9. Дождитесь завершения публикации. Ссылка появится в **Settings → Pages**. Обычно она выглядит так: `https://ВАШ-ЛОГИН.github.io/helpvet-preview/`.
10. Откройте эту HTTPS-ссылку с телефона. К компьютеру подключаться не нужно.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что загружать

```text
index.html
clinic.html
app.js
style.css
assets/
README.md
.nojekyll
.gitignore
```

Скрытые служебные файлы могут не отображаться в Проводнике. Если не удаётся загрузить `.nojekyll` через браузер, остальные файлы этого проекта также подходят для публикации из ветки.

## Что проверить на телефоне

- Первый экран, логотип и фотография не обрезаются.
- Меню под первым экраном переводит к нужным разделам.
- Кнопки, направления услуг, телефон и схема открываются.
- Животные плавно выглядывают при прокрутке вниз и прячутся при движении вверх.
- Форма не выходит за ширину экрана; поля удобно заполнять.
- Для сравнения проверьте портретный и горизонтальный режимы.

После обновления файлов на GitHub дождитесь следующей публикации. Если осталась старая версия, обновите страницу или откройте ссылку в приватной вкладке.

## Границы демонстрации

- Форма проверяет заполнение, но **не отправляет и не сохраняет заявки**. После нажатия она сообщает об этом.
- `clinic.html` — **общедоступный макет кабинета**, без входа и без реальных данных. Это не защищённая административная панель.
- Редактор кабинета только скачивает черновик настроек JSON; публичный сайт он не меняет.
- Цены и график ещё не заполнены.
- Фотографии животных и упрощённая схема созданы/отредактированы с помощью ImageGen. Перед рабочей публикацией схему нужно сверить с оригинальной схемой клиники.
- Репозиторий и сайт предназначены для просмотра дизайна. Не добавляйте пароли, персональные данные или реальные заявки.
- Добавлен `noindex,nofollow` для поисковиков. Это просьба не индексировать макет, не ограничение доступа.
- Серверная часть и база данных для будущего рабочего сайта не входят в этот комплект.

## Локально

Можно открыть `index.html` двойным щелчком. Для телефона используйте ссылку GitHub Pages после публикации.
